# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is supported with security updates.

## Reporting a Vulnerability

Do not open a public issue for security problems. Report them privately through
GitHub's "Report a vulnerability" option on the repository's Security tab.
Include the affected script, steps to reproduce, and the potential impact.
Reports are reviewed on a best-effort basis, and you will receive a response
once the report has been triaged.
